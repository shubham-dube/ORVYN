# Roadmap

Each phase ends with something used daily on the phone, not with a demo.

| Phase | Ships | Done when |
|---|---|---|
| **0 · Groundwork** | Docs, decisions, design direction chosen, monorepo + CI, design tokens | Founder picks a design direction |
| **1 · Foundation** | Sign-in, devices, feature switches, admin, sync engine, notifications (Android, web/PWA, Windows), design system in web + Flutter, deploy + backups + monitoring | Founder signs in on phone, web and PC; a test notification arrives everywhere and dismisses everywhere |
| **2 · Today** (Tasks + Calendar) | Natural-language capture, timeline, recurring, reminders, auto-plan, Google Calendar sync, widget, Windows hotkey, extension capture | Founder uses it instead of his current to-do/calendar for 2 weeks |
| **3 · Drop + Money** | Universal inbox (text/voice/photo); expenses with SMS/notification capture (Android), receipts, statements, budgets | A month of spending captured with < 1 minute of manual entry per day |
| **4 · Vault + Library** | Zero-knowledge vault; documents auto-organised with expiries → reminders | Passwords and IDs moved in; "my PAN card" finds it in one step |
| **5 · Assistant** | Chat over all modules with actions and confirmations | Daily questions answered without opening modules |
| **6 · Chat** | E2E encrypted chat with friends; shared cards | Friends invited with chosen features |
| **7 · IPO desk + Jobs + Brief** | IPO calendar and analyst; JobOS inside ORVYN; morning brief | — |
